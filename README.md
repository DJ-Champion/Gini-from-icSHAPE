# Gini-from-icSHAPE
Computes per-transcript population Gini coefficients of icSHAPE reactivity for human (HEK293) and mouse (mESC), in two compartments (nucleoplasm, cytoplasm), at four region granularities (full, 5UTR, CDS, 3UTR). Output is a long-format TSV ready for the half-life join in R downstream.
